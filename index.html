📖 Cara setup Supabase (klik)
1. Buka supabase.com → Sign up gratis
2. Buat project baru
3. Buka Project Settings → API
4. Copy Project URL dan anon public key
5. Buka SQL Editor, jalankan SQL:
CREATE TABLE IF NOT EXISTS kazs_store ( store_id TEXT NOT NULL, key TEXT NOT NULL, value TEXT, updated_at TIMESTAMPTZ DEFAULT NOW(), PRIMARY KEY (store_id, key) ); ALTER TABLE kazs_store ENABLE ROW LEVEL SECURITY; CREATE POLICY "public_all" ON kazs_store FOR ALL USING (true) WITH CHECK (true);
6. Isi form di atas → klik Simpan & Hubungkan

Download & Update APK
📱 Aplikasi ini adalah Progressive Web App (PWA) yang bisa dipasang langsung di HP Android/iOS tanpa perlu download dari Play Store.
Cara Install di HP:
1. Buka halaman ini di browser Chrome/Safari
2. Ketuk tombol "⋮" (tiga titik) di pojok browser
3. Pilih "Tambahkan ke Layar Utama" atau "Install App"
4. Aplikasi akan muncul di home screen seperti APK biasa
✅ Bisa diupdate? Ya! Data tersimpan di perangkat. Untuk fitur baru, cukup buka kembali link aplikasi ini dari browser — semua data lama tetap ada.
